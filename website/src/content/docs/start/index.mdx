ReviewStage drafts a pull-request review from the real diff and stages it for you. You tick the findings worth posting and post them under your own GitHub name. Nothing reaches GitHub until you click.

```bash
npx reviewstage
```

## What you get

- A **queue** of the PRs waiting for your review, on your laptop and on your phone.
- A **drafted review** for each one: an assessment, then findings with file and line, every one editable.
- **Post** as a plain `COMMENT` review, as you. **Approve** is a separate click.
- A **learnings loop**: what you drop or reword shapes the next review of that repository.
- Reviews run on **your own Claude plan**, through [Claude Code](https://docs.anthropic.com/en/docs/claude-code), only when you click.

It is a reviewer's assistant, not a review bot: it never posts on its own, never posts as a bot, never requests changes, and never approves. The agent can only produce a file; every write to GitHub is your click with your token.
