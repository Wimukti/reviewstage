# Awesome lists

Lists send steady traffic for months after launch day. File each by hand, through each list's
own form — awesome-claude-code's maintainer restricts accounts that bypass the form or submit
generated recommendations.

## awesome-claude-code (hesreallyhim/awesome-claude-code)

- **When:** from D14 (the resource must be at least 14 days old with active development) — or
  any time once the repo has 100+ stars.
- **How:** Issues → New issue → the **Resource** form (web UI only). One resource per form.
- **Category:** Tooling (or "Applications" if the form offers it).
- **Name:** ReviewStage
- **URL:** https://github.com/Wimukti/reviewstage
- **Description** (one line, what it does, no emoji, not addressed to the reader):

  Desktop and phone PR review assistant that drafts reviews with Claude Code on the reviewer's own plan and posts only the findings the reviewer selects, under their own GitHub account.

- **License:** MIT

## awesome-selfhosted (awesome-selfhosted/awesome-selfhosted-data)

- **When:** not before 01/12/27 — the list requires the project's first release to be at least

- **Category:** Software Development - Project Management (or the closest current category).
